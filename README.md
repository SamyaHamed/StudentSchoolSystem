# Student-School Management System

This project is a **training application** built with **.NET** that manages students and schools data.  
It provides a simple interface for creating, reading, updating, and deleting (CRUD) records of students and schools.

## Features

- Manage **students** (add, edit, delete, view).
- Manage **schools** (add, edit, delete, view).
- Relational database design: each student is linked to a school.
- Built with **.NET** and supports **Entity Framework Core**.
- Clean and modular code for learning purposes.

## Tech Stack

- **Backend**: .NET (C#)
- **Database**: SQLite 
- **ORM**: Entity Framework Core
- **IDE**: Rider
